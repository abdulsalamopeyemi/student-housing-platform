## Rules

- No meaningless names such as `image1.jpg`.
- Record the source and permission.
- Write useful alt text.
- Prefer honest property photography over misleading wide-angle edits.
- Keep original assets as well as optimized production versions.
- Do not use web images when usage rights are unclear.
