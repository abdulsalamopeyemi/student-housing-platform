# Design System

## Direction

Trustworthy, warm, modern, and student-friendly.

Avoid:

- generic luxury-real-estate styling
- institutional school-portal styling
- decorative UI that hides important information

## Working palette

| Token | Value | Use |
|---|---|---|
| Forest | `#173F34` | Primary brand, navigation, buttons |
| Emerald | `#2D6A4F` | Secondary emphasis, positive states |
| Gold | `#D6A448` | Accent and highlights |
| Cream | `#F7F3E9` | Warm backgrounds |
| Paper | `#FFFDF7` | Main surfaces |
| Ink | `#112A23` | Main text |
| Muted | `#66746F` | Secondary text |
| Danger | `#B42318` | Errors/destructive states |
| Border | `#DCE6DF` | Dividers and controls |

## Principles

- Mobile first.
- Price and availability stay visible.
- Verification labels must correspond to a real verification process.
- Use clear hierarchy rather than many fonts.
- Every control must be keyboard usable.
- Important text must have sufficient contrast.
- Build reusable components before duplicating page-specific markup.

## Shape

- Cards: roughly 16–24px radius depending on hierarchy.
- Buttons: roughly 12–16px radius.
- Prefer whitespace, hierarchy, and typography before decorative effects.
